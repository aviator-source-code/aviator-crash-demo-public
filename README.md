# Aviator Crash Demo — Web Game Mechanics (Public Showcase)

By **Amir Hamza** — Game & Web Developer

Live platform (under development): N/A

## What this repo is
Public, recruiter-safe demo of crash-game front-end mechanics:
- Round + multiplier logic, flight SVG, live feed + rounds history
- Bet controls, balance / deposit / withdraw UI (demo only, no real money in this repo)
- Admin (`admin.html`) + login (`login.html`) flows with localStorage demo
- Responsive HTML/CSS/JS, no build step

## Run locally
Just open `index.html` in a browser, or:
```
npx serve .
# then open http://localhost:3000
```
